# Corrofy Website



Official organization portfolio website for **Corrofy**, showcasing systems work, technical capabilities, team directory, and contact channels.



**Live Site:** [https://corrofy.github.io/Corrofy_website/](https://corrofy.github.io/Corrofy_website/)



---



## Tech Stack & Architecture

* **Framework:** React + TypeScript

* **Build Tool:** Vite (configured with subpath deployment for GitHub Pages)

* **Styling:** Tailwind CSS (`@tailwindcss/vite`)

* **Themes:** Color palette derived from the moodboard in `public/assets`



---



## Local Development



1. **Clone the repository:**

   ```bash

   git clone https://github.com/Corrofy/Corrofy_website.git

   cd Corrofy_website

   ```



2. **Install dependencies:**

   ```bash

   npm install

   ```



3. **Run the development server:**

   ```bash

   npm run dev

   ```



4. **Build for production:**

   ```bash

   npm run build

   ```



---



## Deployment

This repository is automatically built and deployed to **GitHub Pages** via GitHub Actions (`.github/workflows/deploy.yml`) on every push to `main`.
